🏪 הגדרת שעון נוכחות

3 שלבים פשוטים — ~10 דקות
1

יצירת פרויקט Firebase (חינמי)

Firebase הוא שירות חינמי של גוגל שמאחסן את נתוני הנוכחות בענן כך שגם הטאבלט וגם הנייד רואים אותו דבר בזמן אמת.

1. פתח console.firebase.google.com וכנס עם חשבון Google שלך.
2. לחץ Add project → שם: super-taanug-attendance
3. Google Analytics — לא חובה, אפשר לכבות ולהמשיך.
4. המתן שהפרויקט ייווצר ולחץ Continue.

2

קבלת פרטי ה-Firebase Config

1. בדף הפרויקט לחץ על אייקון </> (Web app).
2. שם האפליקציה: attendance → Register app.
3. תקבל בלוק קוד כזה: 

const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "super-taanug-attendance.firebaseapp.com",
  projectId: "super-taanug-attendance",
  storageBucket: "super-taanug-attendance.appspot.com",
  messagingSenderId: "12345678",
  appId: "1:12345678:web:abcdef"
};

4. העתק את הערכים האלה.
5. פתח את kiosk.html ואת admin.html בפנקס רשימות (Notepad++, VSCode וכו׳).
6. מצא את הקטע: 

const FIREBASE_CONFIG = {
  apiKey:            "PASTE_YOUR_API_KEY",
  ...

7. החלף כל ערך PASTE_YOUR_... בערך האמיתי שלך. עשה זאת בשני הקבצים.

⚠️ חשוב: הפרטים זהים בשני הקבצים — כפול-הדבק לשניהם.
3

פתיחת Firestore Database

Firebase צריך להפעיל את מסד הנתונים:

1. בצד שמאל בפרויקט Firebase: Firestore Database → Create database.
2. בחר Start in test mode → Next.
3. בחר את האזור הקרוב (europe-west3 — פרנקפורט) → Enable.

⚠️ Test mode מאפשר גישה חינמית ל-30 יום. אחרי 30 יום צריך להוסיף חוקי אבטחה פשוטים (או פשוט לבחור test mode שוב — לעסק פנימי זה מספיק).
4

שינוי הסיסמה (מומלץ)

ב-admin.html מצא: 

const ADMIN_PASSWORD = "taanug2024";

שנה ל-סיסמה שלך ושמור.

5

העלאה לאינטרנט (ב-Cloudflare Pages)

מכיוון שכבר יש לך אתר ב-Cloudflare Pages, פשוט:

1. צור תיקייה חדשה בגיט-האב שלך (או הוסף לאותו ריפו, בתיקייה attendance/).
2. העלה את kiosk.html ו-admin.html.
3. Cloudflare יבנה אוטומטית.

או — לשימוש מקומי בלבד — פשוט פתח את kiosk.html ישירות בדפדפן (לחץ פעמיים).
